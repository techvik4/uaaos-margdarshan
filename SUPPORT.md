# Support

## Questions and usage help

For general usage questions, open a GitHub Discussion if Discussions are enabled for the repository. Otherwise, open an Issue using the question template.

## Bugs and incorrect guidance

Use the bug-report issue template. Include:

- AI agent and exact version;
- selected mode or integration;
- operating system;
- whether `AGENTS.md` was automatically discovered or manually attached;
- expected and actual behaviour;
- minimal sanitized reproduction steps.

## Security issues

Do not report exploitable vulnerabilities publicly. Follow [SECURITY.md](./SECURITY.md).

## What support cannot guarantee

This is a community guidance project. It does not provide guaranteed support response times, paid support, emergency response or guarantees about third-party AI products.
