# Contributing

Thank you for helping improve UAAOS – MARGDARSHAN.

## What feedback is useful?

- Reproducible examples where an agent misunderstood or skipped a rule.
- Verified compatibility information for a specific agent, version and mode.
- Clear wording improvements that make instructions safer or easier to follow.
- Missing edge cases for dependency management, recovery, security, privacy or testing.
- Documentation corrections supported by reliable sources.

## Before opening an issue

1. Search existing issues to avoid duplicates.
2. State the agent, version, operating system and workflow used.
3. Explain the expected behaviour and what actually happened.
4. Include minimal, sanitized reproduction steps.
5. Remove tokens, passwords, private paths and personal information.

## Before proposing a pull request

- Keep `AGENTS.md` as the only canonical master rule set.
- Avoid copying the full master instructions into other files.
- Explain why the change is needed and what problem it solves.
- Cite official documentation for claims about agent compatibility.
- Do not add instructions that bypass user approval, security controls or privacy protections.
- Update relevant documentation and `CHANGELOG.md`.
- Test Markdown links and formatting.

## Licensing status

The project owner has not selected an open-source license yet. Until the licensing policy is published, please use Issues for suggestions and do not assume that submitting content grants a general right to reuse or redistribute repository material. Confirm contribution terms with the maintainer before submitting substantial third-party or code content.

## Review

Maintainers may request clarification, changes or evidence. A pull request is not accepted until it is explicitly merged.
