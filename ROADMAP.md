# Roadmap

This roadmap is a set of proposals, not a promise or delivery schedule. Priorities may change based on real-world feedback and testing.

## Current foundation — v1.2

- [x] Single canonical `AGENTS.md` master guidance.
- [x] Activation and session-resume message.
- [x] Safe autonomy and approval boundaries.
- [x] Dependency checks and unnecessary-update avoidance.
- [x] Micro-task development and verification.
- [x] Checkpoint and interruption recovery guidance.
- [x] Research, security, privacy and honest status reporting.
- [x] Beginner-friendly user communication.

## Proposed next steps

### v1.3 — Validation and usability
- [ ] Create a repeatable instruction-compliance test set.
- [ ] Test file discovery against specific agent products and versions.
- [ ] Improve beginner quick-start examples.
- [ ] Review instruction length against relevant context limits.

### v1.4 — Recovery and engineering workflows
- [ ] Add sample project-state and recovery-record templates.
- [ ] Add sample acceptance criteria and task decomposition examples.
- [ ] Add guidance for multi-agent conflict prevention.
- [ ] Add release-readiness and dependency review examples.

### v2.0 — Evidence-led expansion
- [ ] Publish compatibility results only after repeatable tests.
- [ ] Consider optional, minimal native loader examples without duplicating master rules.
- [ ] Review community feedback and security lessons.
- [ ] Revisit license and contribution policy with the project owner.

## Priority rule

Security, privacy, correctness and user trust take precedence over feature count or release speed.
